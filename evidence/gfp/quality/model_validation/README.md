# GFP 预测器验证集消融

在冻结实验的三个初始观测集上各拟合一次 Ridge 和随机森林，保持原编码及参数。每个种子只评价独立的 120 条验证记录，共 360 条记录，358 个不同变体。采集候选的标签和最终预测留出标签均未参与训练或评分。已复算冻结基准的六条验证记录及原指标。[逐种子指标](validation_by_seed.csv) · [逐变体预测](validation_predictions.csv) · [验证收据](summary.json)

| 验证指标，三种子均值 | Ridge | 随机森林 |
|---|---:|---:|
| Spearman | 0.430 | 0.342 |
| Pearson | 0.442 | 0.387 |
| MSE | 0.724 | 0.778 |
| 高于野生型的平均精度 | 0.241 | 0.212 |
| 高于野生型的 P@5 / P@10 | 0.267 / 0.200 | 0.133 / 0.230 |
| 验证集荧光前 10% 的平均精度 | 0.203 | 0.168 |
| 验证集荧光前 10% 的 P@5 / P@10 | 0.200 / 0.133 | 0.133 / 0.163 |

Ridge 在两个发现阈值的 P@5、平均精度和全局相关性上较高。随机森林在两种阈值的 P@10 上较高。这里的 P@K 对并列预测按切点并列项均匀抽样计算期望命中比例。三个种子的结果支持把 Ridge 作为额外采集基线。冻结协议继续使用随机森林作为正式对照，验证结果没有预先确认任何模型存在迭代采集优势。[指标均值](validation_means.csv)

## 随机森林树间离散度

各验证集上，树间预测标准差和绝对误差的 Spearman 相关分别为 0.533、0.556、0.394。仅保留离散度最低的四分之一时，各折 MAE 的均值从 0.679 降为 0.395。均值预测 ±1.96 倍树间离散度的经验覆盖率均值为 75.3%。这里的树间离散度可以辅助标记可能出现大误差的输入。该区间未经校准，Ridge 的现有接口也未估计预测区间。降低低离散度子集的误差不能推出主动探索会发现更高荧光的候选。[逐折误差和覆盖](summary.json)
